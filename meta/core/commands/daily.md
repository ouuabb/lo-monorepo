## daily — 创建今日日记

**用法:** `lo daily`

创建包含今日模板的日记文件。模板包含今日完成、待办事项和想法记录三个区块。

### 模板内容

创建的日记文件包含以下模板区块:

- **今日完成** — 记录今天已完成的事项
- **待办事项** — 列出待完成的任务
- **想法记录** — 随手记录灵感和思考

### 文件命名

文件命名格式为 `YYYY-MM-DD-daily.md`，存储在 `resources/` 目录下。

### 示例

```
lo daily
```

### 注意事项

- 创建时自动归入「日记」分类并添加 `daily` 标签，状态为 `draft`
- 同一日期重复运行 `lo daily` 是**幂等**的：当日日记已存在时直接返回已有资源（提示 rid），不会重复创建、不会覆盖已有内容
- 若磁盘上已存在 `resources/YYYY-MM-DD-daily.md` 但尚未登记，`lo daily` 同样不会覆盖，会提示先 `lo add` 登记该文件
- 创建后资源**直接入库**（无需 `lo add`），编辑用 `lo edit <rid>`
- 可通过 `lo new "标题" --template daily` 使用模板创建其他日记
